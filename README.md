# Web Development Portfolio & Agency Monorepo

A collection of 5 production-grade websites built with **Vite + React + Tailwind CSS + Framer Motion**.

## Projects

| Directory | Name | Category | Notes |
| :--- | :--- | :--- | :--- |
| [`01-agency`](./01-agency) | **Vespera Digital** | Web Development Agency | Primary agency site (not part of the portfolio showcase) |
| [`02-aether-ai`](./02-aether-ai) | **Aether** | AI Infrastructure SaaS | Portfolio #1 — Dark telemetry UI, interactive pricing & SDK switcher |
| [`03-kanso-atelier`](./03-kanso-atelier) | **Kanso Atelier** | Architecture & Interiors | Portfolio #2 — Editorial minimalist gallery, filterable projects & modals |
| [`04-solstice-roasters`](./04-solstice-roasters) | **Solstice Roasters** | Specialty Coffee Roastery | Portfolio #3 — Interactive flavor explorer, brew guides & shopping cart |
| [`05-meridian-pay`](./05-meridian-pay) | **Meridian** | Global Treasury & Fintech | Portfolio #4 — Interactive FX calculator, 3D card preview & workflow tabs |

## Running Locally

Each site is a standalone Vite + React application:

```bash
cd 01-agency
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```

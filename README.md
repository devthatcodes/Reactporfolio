# Web Development Portfolio & Agency Monorepo (Active Theory Edition)

A collection of 5 interactive, WebGL-powered flagship websites engineered with **Vite + React + Tailwind CSS + Framer Motion + Custom GLSL Shaders + Web Audio API Procedural Synthesizers**.

Each application features:
- **Real-Time 60fps WebGL / GLSL Fragment Shaders** reactive to cursor position, cursor velocity, scroll inertia, and active portal state (with graceful 2D Canvas fallbacks).
- **Multi-Slice Cybernetic & Architectural Portal Transitions** between views, sections, and fullscreen case study takeovers.
- **3D Perspective Work Stream Reels & Interactive Fullscreen Portals** modeled after `activetheory.net/work`.
- **Procedural Web Audio API Sound Engines** (zero external audio dependencies) with hover micro-chirps, harmonic lock clicks, and sub-bass portal sweeps.
- **Kinetic Scramble / Decode Typography & Dual-Ring Magnetic Reticle Cursors** with live peripheral HUD telemetry.

## Running Locally

Each site is a standalone Vite + React application:

```bash
cd 01-agency
npm install
npm run dev
```

To verify production builds across any project:

```bash
npm run build
```

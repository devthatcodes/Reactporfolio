A collection of 5 production-grade websites engineered with **Vite + React + Tailwind CSS + Framer Motion**, each featuring its own **completely distinct, industry-authentic motion language, scroll choreography, cursor physics, and interactive showcase**.

## Running Locally

Each site is a standalone Vite + React application:

```bash
cd 01-agency
npm install
npm run dev
```

To verify production builds across any project:

```bash
npm run build
```
